一键接入 API / MCP

查询日报、搜索资讯和 CVE。MCP 给 Cursor / Claude 用，REST API 给脚本和平台用。完整文档：API调用说明.md

MCP 一键接入

克隆仓库后用 Cursor 打开该目录（已含 .cursor/mcp.json），在 Settings → MCP 启用 secdaily。

Cursor / Claude Desktop 配置 
{
  "mcpServers": {
    "secdaily": {
      "command": "python",
      "args": ["mcp_server.py"],
      "cwd": "替换为 SECDaily 仓库根目录"
    }
  }
}
  • secdaily_search 关键词搜索
  • secdaily_get_digest 某日日报
  • secdaily_search_cves 查 CVE
  • secdaily_get_summary AI 总结

REST API 一键接入

Base URL：http://127.0.0.1:8765/api/v1。默认只监听本机。

启动服务 
git clone {{ github_url }}.git
cd SECDaily
python api_server.py
  • OpenAPI：/api/v1/openapi.json
  • 可选请求头：X-API-Key
  • 分页：page / pageSize（最大 100）

API 接口

方法 路径 说明 调用示例
GET /api/v1/health 健康检查、最新日期 curl http://127.0.0.1:8765/api/v1/health
GET /api/v1/dates 可用日报日期，可加 year、limit curl "http://127.0.0.1:8765/api/v1/dates?year=2026&limit=7"
GET /api/v1/digest 最新一天日报 curl http://127.0.0.1:8765/api/v1/digest
GET /api/v1/digest/{date} 指定日期日报，可 cveOnly、source curl "http://127.0.0.1:8765/api/v1/digest/2026-05-28?cveOnly=true&pageSize=10"
GET /api/v1/articles 关键词搜索标题 / 来源 / CVE curl "http://127.0.0.1:8765/api/v1/articles?q=MCP&pageSize=5"
GET /api/v1/cves 按 CVE 编号检索 curl "http://127.0.0.1:8765/api/v1/cves?q=2026-4893"
GET /api/v1/sources 来源列表，可加 date curl "http://127.0.0.1:8765/api/v1/sources?date=2026-05-28"
GET /api/v1/summary/{date} 当日 AI 总结（若已生成） curl http://127.0.0.1:8765/api/v1/summary/2025-12-03
POST /api/v1/analyze 需求文本 8 类安全评估 见下方 Python / curl 示例
GET /api/v1/openapi.json OpenAPI 描述 curl http://127.0.0.1:8765/api/v1/openapi.json

调用示例

启动后在终端执行 
python api_server.py
curl http://127.0.0.1:8765/api/v1/health
curl "http://127.0.0.1:8765/api/v1/dates?limit=7"
curl http://127.0.0.1:8765/api/v1/digest
curl "http://127.0.0.1:8765/api/v1/digest/2026-05-28?cveOnly=true&pageSize=10"
curl "http://127.0.0.1:8765/api/v1/articles?q=MCP&from=2026-04-01&pageSize=5"
curl "http://127.0.0.1:8765/api/v1/cves?q=2026-4893"
curl "http://127.0.0.1:8765/api/v1/sources?date=2026-05-28"
curl -X POST http://127.0.0.1:8765/api/v1/analyze -H "Content-Type: application/json" -d "{\"content\":\"需求：用户注册登录并绑定银行卡支付\",\"useKeywordAnalysis\":true}"
Windows PowerShell 
python api_server.py
Invoke-RestMethod http://127.0.0.1:8765/api/v1/health
Invoke-RestMethod "http://127.0.0.1:8765/api/v1/articles?q=勒索&pageSize=5"
(Invoke-RestMethod "http://127.0.0.1:8765/api/v1/cves?q=2026-4893").data
Invoke-RestMethod -Method Post http://127.0.0.1:8765/api/v1/analyze -ContentType "application/json" -Body '{"content":"需求：用户注册登录并绑定银行卡支付","useKeywordAnalysis":true}'
Python requests 
import requests

base = "http://127.0.0.1:8765/api/v1"
print(requests.get(f"{base}/health").json()["latestDate"])
digest = requests.get(f"{base}/digest", params={"pageSize": 5}).json()
print(digest["date"], digest["stats"])
news = requests.get(f"{base}/articles", params={"q": "MCP", "pageSize": 5}).json()
for item in news["data"]:
    print(item["date"], item["title"], item["url"])
cves = requests.get(f"{base}/cves", params={"q": "2026-4893"}).json()
print(cves["data"])
在 Cursor / Claude 里直接说 
用 secdaily 查最近关于 MCP 的资讯
用 secdaily_get_digest 看今天的安全日报，只要含 CVE 的

用 secdaily_list_sources 列出 2026-05-28 的资讯来源
用 secdaily_get_summary 读取最近一份 AI 总结
